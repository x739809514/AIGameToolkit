# 2D 混合树与骨骼遮罩

动作编辑器工具栏提供独立设置弹窗，包括动作节点列表、XY 参数图、独立 Y Bot 预览与骨骼遮罩。配置写入 `ModelEditorState.blendTree`，旧工作台默认禁用，不改变已有时间轴参数。

支持两种混合方式：

- 骨骼分层混合：按节点顺序对所选骨骼的局部位置、旋转和缩放叠加。权重 0 保持原姿态，权重 1 使用新姿态；后层覆盖前层，重叠骨骼可按权重过渡。
- 2D XY 距离混合：根据参数点与动作节点的距离平方反比计算权重，落在节点上时准确使用该节点；相同坐标的节点按各自权重归一化。每个骨骼只归一化对其有效的节点权重。此算法不宣称与 Unity 2D Directional／Freeform Cartesian 完全一致。

每个节点引用本工作台模型和动画索引，记录源动画时长、名称、XY 坐标、权重、启用状态与遮罩。最多 16 个动作，XY 范围 −1 到 1，循环时长 0.1–300 秒。默认各动作按原始速度循环；开启同步动作周期后按归一化时间同步采样。

遮罩支持基础人形的 22 个控制关节。预设包括全身、上半身、下半身、躯干、头颈、左右手臂、左右腿脚。实际 Y Bot 的变形骨骼按名称和最近的控制祖先映射到部位，包含重复骨骼、手指和辅助骨骼；未选中的局部姿态保持原样，父骨骼运动仍按层级传递。旋转使用四元数 slerp 并归一化。

弹窗维护未保存草稿和独立 ModelScene，拖动参数与修改遮罩实时更新预览。应用时按 30 fps 将当前混合预览烘焙成独立的骨骼动画 FBX，使用弹窗中的新动作名称，加入左侧动作列表并自动选中；停用实时混合树与时间轴预览。新动作可拖入时间轴、再次参与混合或下载，源 FBX 保留。配置、权重与遮罩随工作台保存，删除模型会清理对应混合节点。取消丢弃弹窗草稿。

视频导出通过相同 MotionPlayer 采样逻辑渲染，校验所有源模型归属与循环时长，视频素材保存 `motionBlend` 参数快照。应用生成的新 FBX 保存 `motionBlend` 参数快照，烘焙使用与预览相同的 MotionPlayer，包括骨骼遮罩、XY 权重、周期同步与忽略位移设置；文件仅含骨骼与动画，可独立回读，后续播放不依赖源素材。

验证包括 XY 端点与重复节点、非法数据和跨实例引用拒绝、真实 Y Bot 上下半身组合、未选择关节保留、辅助／变形骨骼同步、确定性采样、持久化与视频范围。桌面验证通过逐关节操作、分层应用、实际 XY 指针拖动、独立预览、MP4 导出、切换恢复、取消与紧凑布局。
