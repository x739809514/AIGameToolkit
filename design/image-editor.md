# 图片编辑器

版本 0.1.3。中间预览区提供画笔修改、裁切、去除背景入口，为当前图片打开独立 Electron 窗口。同一原图重复点击工具时复用窗口。上传图片与生成图片都支持编辑。

## 操作与结果

局部修改用画笔涂满区域或自由圈选围住区域，支持擦除、调节大小、撤销、重做与全选。紫色显示选区，用户输入 Prompt 后提交。后台将原图标准化为 PNG，导出同尺寸遮罩，透明部分表示修改区域。调用 OpenAI Images edits 后，结果恢复为原图尺寸并按遮罩合成；未选中的像素逐像素保留。全图生成可能影响选区内部结构，圈选边缘效果仍受模型输出影响。

裁切支持拖动与像素输入，在本机复制指定范围的 RGBA 像素，保留透明度，无 API 调用。背景移除使用图片编辑 API 的透明背景和 PNG 输出参数，验证实际返回透明度；若无透明像素则显示失败，不将不透明结果标记为去背景成功。去背景为模型修改，主体细节可能变化。

编辑结果保存为新素材，记录源图片与操作类型，原图不覆盖。工作台预览仍停留在提交时选中的图片时，自动选择结果；用户期间切换预览则保留其选择。结果可应用为视频首帧。AI 任务显示进度，失败保留选区与 Prompt；关闭编辑窗口不会取消已提交任务。未提交的选区或文字有关闭确认。

## 安全与持久化

主进程持有 API Key，编辑窗口只通过受限 preload 调用 IPC。仅主窗口与已注册编辑窗口的主 frame 能访问 IPC。原图、遮罩与结果存放本地工作区；SQLite 保存操作与任务快照。编辑窗口以标准 PNG data URI 绘制画布，避免媒体协议跨源污染 Canvas。编辑器图片上限 1600 万像素，遮罩上限 4 MB。

供应商参数依据 [Images edit](https://developers.openai.com/api/reference/resources/images/methods/edit) 与 [Image generation](https://developers.openai.com/api/docs/guides/image-generation)。局部修改与去背景需要相应模型权限及 OpenAI 凭据。

## 验证

单元与请求测试覆盖精确裁切、坐标范围、遮罩校验、选区外像素保留、无需 Key 的本机裁切、遮罩上传和透明背景参数。桌面交互检查使用外部导入素材验证画笔、撤销重做、窗口复用、裁切保存及主窗口同步。安装包检查运行真实打包应用，验证独立窗口加载与裁切。上述检查不调用收费模型；实际模型的修改质量和主体保留程度待账号验证。
