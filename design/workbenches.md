# Worktree 与工作台架构

版本 0.3.2，2026-10-12。层级为 Worktree → 多个工作台。Worktree 是 App 内的本地创作目录分组；工作台种类提供 `image-video` 与 `video-frames`。

## 窗口与导航

启动 Dashboard 采用 Gallery 布局，展示已注册的可用工作台模板和已有 Worktree。卡片展示封面、模板名称、简介与能力标签；点击后弹出创建对话框，选择所属 Worktree 与名称。已有 Worktree 卡片显示名称、工作台数量和最近使用信息，点击进入最近打开的工作台；空 Worktree 弹出创建工作台对话框并绑定该目录。进入后通过左侧 Worktree 树切换已有实例。首次新建会建立“默认 Worktree”。所有工作台复用一个主窗口；图片编辑器保留独立窗口并绑定原工作台。

左侧为可滚动的 Worktree 树。Worktree 可展开、折叠，显示名称和工作台数量；顶部加号创建 Worktree，并添加第一个图片与视频工作台。分组旁加号在该 Worktree 中创建工作台，子条目点击切换，当前工作台高亮。右侧文件树的根为当前 Worktree，显示同组全部工作台目录、素材和其他可访问文件；目录名以工作台名称展示，悬停可查看真实相对路径。

聊天、草稿、生成任务、模型偏好及预览选择按工作台独立保存。切换后后台任务继续；异步保存和图片编辑仍写回原工作台。右侧文件树监听同组素材变更。点击其他工作台的图片或视频，将其复制导入当前工作台，再用于预览、编辑或视频首帧；原素材保留。

## 存储与迁移

App 根目录 `workbenches.json` 使用 version 2，保存 `worktrees` 与 `workbenches`，每个工作台包含 `worktreeId`。目录由主进程生成，采用临时文件加重命名保存。

新增 Worktree 路径为 `worktrees/<Worktree UUID>`；其工作台分别存入 `workbenches/<Workbench UUID>` 子目录，每个使用独立 SQLite、Store、Service 与素材目录。

兼容旧数据：“默认 Worktree”的 `legacy` 根继续使用原 App 数据目录；旧工作台仍使用根目录或原 `workbenches/<UUID>`，无需移动媒体文件。version 1 目录自动升级，已有草稿、聊天和远程任务 ID 保留。首次从空数据创建工作台也采用默认根。

API Key 使用 App 级加密凭据库共用，不复制明文。模型偏好按工作台保存，新工作台复制同组最近打开工作台的设置。Worktree 目录视图隐藏凭据、其他 Worktree、Electron 缓存及内部 SQLite 文件；文件读取拒绝绝对路径、越界路径及符号链接。

## API 与隔离

工作台业务 API 显式绑定实例 ID，主窗口切换期间也路由到原 Service。编辑器不能访问其他工作台。媒体协议只解析当前工作台素材；跨工作台复用通过当前 Worktree 的相对文件路径进行校验并复制导入，不直接借用其他实例的素材 ID。

目录列表聚合同组全部工作台的素材元数据，保留真实相对路径；读取、原生打开目录及文件定位均使用当前 Worktree 根。其他 Worktree 不会出现在此树中。

## 验证与范围

核心检查覆盖旧目录迁移、独立数据、共享凭据、多个工作台归属同组、不同组目录隔离和重启保留。桌面检查通过实际加号创建工作台和 Worktree，验证唯一主窗口、目录切换、同组图片复用、草稿恢复、跨组访问拒绝和滚动；安装包验证层级、目录标题及原有媒体与编辑功能。生成请求使用测试响应，不消费用户余额。

支持右键删除工作台实例，忙碌、未确认的付费任务或本地操作期间禁止删除；仅将实例数据移至废纸篓。同组公共文件保留。当前不包含 Worktree 删除、改名、移动、外部目录绑定或云同步。

## 视频与动画帧模板

`video-frames` 复用工作台隔离、凭据、设置、文件树与图片编辑器。左侧提供正常／拆帧模式、媒体上传及聊天记录；右侧上方预览，下方 Timeline，拆帧数量位于 Timeline 底部，默认 20、范围 1–240。

正常模式支持 H3 纯文字、单首帧、首尾帧与参考素材。付费任务保存视频后自动提取帧，数量使用提交时快照。拆帧模式只提取上传视频的本地 PNG；重新拆帧不再提交生成任务。提取序列按视频时长均匀取样，记录视频 ID、序列 ID、帧索引与时间戳，序列独立保存。中断提取标为失败，用户可本地重试；拆帧失败不改变已成功保存的视频任务。

点击帧后可文字改图或画笔局部修改。新图片更新对应 Timeline 帧，记录版本与原始帧，可恢复原帧。编辑器绑定原工作台，切换实例不影响结果归属。
