# 图片与视频的精确输出尺寸

图片与视频创作面板分别保存目标宽高和适配方式，生成时复制进任务，后续修改草稿不影响正在生成的任务。旧草稿、旧任务没有此字段时仍按原流程处理。

图片 API 沿用原有的 1024×1024、1536×1024、1024×1536 档位，根据目标比例选择；视频 API 沿用模型设置里的有效档位，不发送自定义像素参数。生成后使用内置 FFmpeg 适配，ffprobe 检查实际宽高及方形像素，校验成功才保存为生成结果。

提供先等比缩放再居中裁剪、先居中裁剪再等比缩放、完整画面居中黑边补齐。均为本地处理，不包含 AI 补绘。目标为 16–8192 的整数宽高，总像素不超过 1600 万；视频偶数尺寸用 H.264 yuv420p，奇数尺寸用 yuv444p，后者播放器兼容性较低。

图片 API 结果先缓存到任务的 pending PNG；本地适配或保存失败时可以重试，不重复生图。视频保存失败继续使用原远程结果地址，不重交生成任务。图片编辑器的局部重绘、去背景保留源图尺寸，不受创作面板设置影响。

验证：tests/output-resolution.test.ts 使用真实 FFmpeg 检查三种适配的奇偶宽高，并用模拟 API 验证任务快照、独立草稿持久化和本地失败重试不重复计费请求。scripts/output-resolution-smoke.cjs 验证源码构建与安装包的界面输入、预设、重启恢复和小窗口滚动。
