# UI 布局编辑器

独立的本地工作台，用于自由摆放图形、文字和角色头像，设计 UI 并交付可再次编辑的 JSON 与 PNG。无需 AI 凭据。

## 使用流程

1. 在 Dashboard 选择「UI 布局编辑器」，选择 Worktree 后创建工作台。
2. 从左侧工具条拖入方块、圆形、线条、多边形、文字、角色 Avatar 或图片，也可以点击构件在画布中添加。「箭头」是绘制工具：点击后在画布按住左键，从起点拖到终点，松开完成；支持连续绘制任意方向，Shift 锁定 45° 倍数，Esc 取消当前绘制并返回选择。只点击不会产生构件，整次拖绘只占一步撤销。A 启用箭头工具，V 返回选择。
3. 在画布拖动构件，拖动四角调整大小，拖动上方圆点旋转。按住 Shift 等比缩放或按 15° 旋转；Shift 点击多选。
4. 双击文字直接输入；右侧可以设置内容、字体、字号、字重和框内对齐。水平支持左 / 中 / 右，垂直支持顶部 / 居中 / 底部，共九种组合，对齐不会改变文字框位置。多边形与线条支持双击或点击「编辑顶点」后拖动顶点。箭头选中后直接显示两端手柄，可拖到原包围框以外，另一端保持不动。
5. 右侧输入位置、尺寸、旋转、不透明度、填充、描边和圆角。描边支持实线、虚线、点线、点划线，以及平头 / 圆头 / 方头端点和尖角 / 圆角 / 斜角拐角。线条与箭头可分别设置起点和终点为无、实心箭头、开放箭头、菱形或圆形，调整箭头大小，并一键反转方向。点击颜色行展开颜色面板，文字、填充、描边及画布背景在各自面板内提供色值、不透明度滑块与百分比输入，0% 为透明、100% 为不透明；整体不透明度独立作用于整个构件。上方「画布」对齐按钮对单个构件以画布为基准，多选时显示「构件」并以选中构件的范围为基准。文字下方相邻的「框内」使用同样六个按钮，提供左 / 中 / 右及顶 / 中 / 底对齐并显示当前选中状态。
6. 图层支持选择、隐藏、锁定、置顶和置底。左侧 Ctrl / ⌘ 点击增减选择，Shift 点击连续范围；「成组」或 ⌘/Ctrl + G 将多个图层合为可折叠的 Group，选择组可整体移动、复制、隐藏和锁定；「取消组合」或 Shift + ⌘/Ctrl + G 解散组。双击图层 / 组名称、F2 或右键「重命名」进入名称输入，Enter 或失焦保存，Esc 取消。右键图层可删除，已锁定图层需先解锁；多选时可删除所选未锁定图层。拖动图层名称调整顺序，插入线指示位置，列表上方显示在画布前面；多选图层可一起移动并保持组内顺序。支持复制、删除、撤销与重做。选中后按 Delete / Backspace 删除未锁定构件，可撤销；文字输入时按键仍用于删字。方向键微调 1px，Shift + 方向键微调 10px；⌘/Ctrl + D 复制，⌘/Ctrl + Z 撤销，Shift + ⌘/Ctrl + Z 重做，⌘/Ctrl + A 全选。
7. 可显示网格、启用 8px 位置吸附，缩放或点击适合画布。按住空格拖动、按住中键拖动，或使用滚动条平移视图。
8. 「导入图片」或 Avatar / 图片属性里的「选择本地图片」支持 PNG、JPEG、WebP。图片统一转换为最大边 1024px 的内嵌 PNG，单个源文件最大 8 MB。Avatar 默认显示角色占位图，可替换为头像或角色图片。
9. 点击「导出 JSON + PNG」，在系统保存对话框中选择位置和 JSON 文件名；默认目录是当前 Worktree，也可以保存到其他位置。同名 PNG 同时导出。任意目标已存在时会提示替换两个文件，取消不会写入。
10. 使用「打开 JSON」重新加载导出的布局继续编辑。图片已包含在 JSON 中，不需要额外资源文件。

## 框选与多选移动

使用「选择」工具（V），从画布或画布外围的空白处按住鼠标左键拖动，出现半透明选框；与选框相交的组件会实时选中，支持向任意方向框选。隐藏、锁定组件及隐藏、锁定组会跳过；旋转组件按旋转后的框判断相交，组作为整体选择。

选中多个组件后拖动其中一个，所有选中组件保持相对位置一起移动。开启 8px 吸附时仅对拖动锚点吸附，再将同一个位移应用于全部组件，避免间距变化。一次拖动对应一次撤销 / 重做，并自动保存。

按住 Shift 框选可追加到当前选择；点击空白处清除选择。Esc、失去窗口焦点或指针取消会取消正在进行的框选，恢复开始前的选择。框选是编辑器临时状态，选框不会进入 JSON 或 PNG；空格 / 中键平移和箭头绘制保持各自工具行为。

## 页面

工作台顶部显示页面页签，点击「添加页面」创建空白界面，继承当前画布尺寸和背景。每页的构件、图层顺序、名称、画布尺寸和背景独立保存；点击页签切换，顶部名称可修改当前页名。页签过多时横向滚动，键盘左右箭头及 Home / End 可切换。最多 30 页，添加和内容编辑支持撤销重做。切换前保留正在编辑的文字并清除构件选择。

原有单页布局仍可打开。增加页面后 JSON 包含全部页面，PNG 导出当前页；导出按钮提示这一范围。自动保存会恢复所有页面和当前页。

## 功能组件与自动布局

左侧可添加 Button、Checkbox、Dropdown 和 Scroll View。右侧「组件功能设置」提供文字、文字颜色、字号、禁用状态及对应控件参数。Checkbox 可以设置默认勾选；Dropdown 每行输入一个选项，失焦保存选项列表，并可选择默认值。

Button 的点击动作可设为显示提示、跳转页面、切换图层 / 组显示或重置控件状态。页面和图层目标通过列表选择，不执行脚本。点击顶部「交互预览」后，按钮执行已配置动作，Checkbox 可切换，Dropdown 可通过鼠标或键盘选择，Scroll View 可滚动并操作内部控件。「重置交互预览」恢复初始状态；预览中的临时值和跳转不会修改设计默认值。Esc 或「返回编辑」退出预览。

Scroll View 是可裁切的父容器。将构件从工具条拖入视口，或在已有构件的「父容器」中指定 Scroll View，即可建立父子关系；左侧可展开查看成员。支持垂直、水平和双向滚动。移动视口时子组件随之移动，删除视口时一并删除内部组件；复制时生成独立的组件和父子关系。

组与 Scroll View 可以设置 Free、Vertical Layout、Horizontal Layout 或 Grid Layout。间距、内边距、交叉轴对齐 / 拉伸及网格列数改变后，实际子组件坐标和尺寸会重新计算。组还可以设置布局区域宽高；Scroll View 使用视口宽高作为布局区域，超出区域的内容可滚动。自动布局按照组件的绘制顺序排列，调整图层顺序可改变布局顺序。

## 数据与导出

布局按工作台独立保存在 SQLite，切换工作台和重启后恢复。JSON 使用 `format: "laputa-ui-layout"`、`version: 1`，包含画布名称、宽高、背景，以及按绘制顺序排列的 `nodes`。构件包含 ID、种类、名称、位置、尺寸、旋转、外观、文字、顶点和可选图片数据；隐藏和锁定状态同样保存。

0.10.3 增加可选 `pages` 和 `activePageId`，每个页面包含独立 ID、名称、宽高、背景及构件。根字段镜像当前页面，供原有画布与 PNG 渲染使用，保存时同步；无这两个字段的旧单页 JSON 保持兼容。整体 JSON 仍限制 24 MB，每页最多 500 个构件，最多 30 页。

0.10.1 增加 `fillOpacity`、`strokeOpacity`（0–1）和 `verticalAlign`（`top` / `middle` / `bottom`）。旧 JSON 缺省时分别采用 1、1 和 `top`，保持既有显示效果。

箭头使用 `type: "arrow"`，与线条一样以 `points` 保存端点，支持移动、缩放、旋转和顶点编辑。线条样式字段为 `strokeStyle`（`solid` / `dashed` / `dotted` / `dash-dot`）、`strokeLinecap`、`strokeLinejoin`、`arrowStart`、`arrowEnd` 和 `arrowSize`（4–100px）。旧 JSON 缺省时保留实线和原有端点、拐角效果，既有线条不增加箭头。箭头端部沿起止线段自动旋转，颜色和透明度跟随描边；画布和 PNG 使用同一渲染。

画布宽高范围 64–4096px，总计最多 1600 万像素，最多 500 个构件；JSON 上限 24 MB。导入和持久化由共享 schema 校验并去除未知字段，图片只允许内嵌 PNG，不接受外部资源地址或 SVG 脚本。

新增构件类型为 `button`、`checkbox`、`dropdown`、`scrollview`，使用可选 `control` 字段保存控件属性，`parentId` 指向所属 Scroll View。组和 Scroll View 使用 `layout` 保存模式、间距、内边距、列数和对齐方式，组的 `frame` 保存布局区域。容器关系不得成环；同一组成员须位于同一父容器内。新增字段缺省不改变旧文档。

每页可包含 `groups`，记录组 ID、名称、成员节点 ID、隐藏和锁定状态。成组保持构件坐标不变，并把成员作为连续图层排列；组元数据独立于节点几何，取消组合可继续单独编辑。组与图层名称参与保存、撤销 / 重做和 JSON 导入导出。隐藏组不会进入 PNG，锁定组不能通过拖动、键盘或删除修改成员。旧布局无需组字段。

PNG 使用与编辑画布相同的 SVG 构件渲染，在原始画布像素尺寸下输出。图层隐藏状态生效，透明背景保留；网格、选择框、变换手柄和编辑器界面不进入输出。主进程校验 PNG 尺寸与 JSON 一致后写入。

成对导出先暂存两个文件，再替换目标；发生写入失败时恢复原文件。不会替换文件夹或符号链接。保存至 Worktree 后，项目文件树自动刷新；用户也可通过顶部按钮显示文件树。

## 范围

当前提供多页面、自由与自动布局、图层组、嵌套 Scroll View 及原生控件交互预览。JSON 保存可编辑设计，PNG 导出当前页面的设计默认状态；不会把临时交互状态写回设计。文字支持单个构件的统一格式及自动换行。
